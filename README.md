# Face-Recognition-Attendance-System

This is a Student Attendance System made using Python and OpenCV.
The system detects faces through webcam and automatically marks attendance.

## Features

* Student Registration
* Face Recognition
* Attendance Marking
* GUI Dashboard
* Excel Attendance Sheet

## Technologies Used

* Python
* OpenCV
* Tkinter
* Pandas

## How to Run

Install libraries:

bash
pip install opencv-contrib-python pandas numpy openpyxl


Run the project:

bash
python login.py
